# 分析和优化 pass

## 代码单元与执行顺序

IRBuilder 生成 Non-SSA；`simplifycfg` 和 `load-store-elim` 同时支持函数及脚本／命令单元，在克隆版本上完成变换后发布。已有 SSA 依赖的 Non-SSA 回退基线不再改写。mem2reg 仅处理函数，不提升脚本主体。

常用管线为 `simplifycfg,load-store-elim,mem2reg`。前两项内部均迭代至稳定；如果读写消除暴露新的常量条件，可再次运行 simplifycfg。分析缓存按版本和 PreservedAnalyses 失效，不复用已删除块的 CFG 或支配结果。

## 控制流与常量去重

`simplifycfg` 对可安全转换的常量条件折叠分支，删除入口不可达区域并修复 PHI，合并 goto 连接的单前驱直线块。条件转换失败时保留原 branch；不因真假目标相同而省略可能抛错的条件检查，也不做一般空中转块绕过。

常量去重沿支配树遍历：同块复用较早定义，跨块仅复用支配当前位置的定义。判等键包括类型、完整形状和精确数据位模式，退出支配子树时撤销该子树的新增常量。兄弟分支不共享尚未共同定义的 ValueId；不移动常量，不为去重新增 PHI。Builder 的块内常量复用仍保留，以避免生成明显重复的指令。

平凡 PHI 简化由 `Transform/phi_simplify` 统一实现，供 simplifycfg 与 mem2reg 复用。只折叠有唯一具体外部来源的 PHI，保留 Undefined 和没有外部来源的循环。

## Non-SSA 槽位读写消除

`load-store-elim` 保留 SlotTable 及工作区语义，不将 slot 提升为 SSA。全局、持久、共享槽位，以及 MaybePack 写入目标或带 SSA 来源的读取，按现有资格规则保守处理；自动捕获分析尚未接入，嵌套函数及其父函数仍跳过该 pass。record 是 SSA 的绑定记录，由读取器拒绝 Non-SSA 中的 record，不参与本 pass 的普通输入分析。

### 可用值格与前向工作列表

未到达的块作为格底；已到达块的每个候选 slot 为 Known(ValueId) 或 Unknown。入口边界的所有槽位是 Unknown，其他块从未到达开始。合并前驱时忽略格底，相同 Known 保留，不同值或任一 Unknown 合并为 Unknown。跨块值还必须严格支配目标块。

在固定 IR 上按原指令顺序计算传递函数：

- load 无条件将对应槽位设为 Known(自己的结果)，无法作为具体值使用时设为 Unknown。
- store 将对应槽位设为 Known(具体输入)，不明确的输入设为 Unknown。
- 动态调用、声明、屏障等可能改变工作区的操作清空受影响信息；写入范围不明确时全部设为 Unknown。
- 无关指令保持状态。

每个槽位的块传递函数是恒等函数或固定状态函数。OUT 变化才将后继加入工作列表；有限高度格上的单调迭代达到不动点，不依赖次数上限。调试构建中检查 OUT 不发生反向状态变化。

### 收敛后的替换

从最终 IN 开始再次顺序扫描。遇到 load 时检查其前方状态；已有可用 Known 值时替换全部使用并删除 load，否则保留首次读取及其未定义变量报错。替换链归一化后再使用，避免缓存继续引用已删除的结果。同值重复 store 和原样写回也可删除。

值转发后尝试折叠 logical_scalar 和全常量元胞构造；as_bool 转换抛错时保留原指令。Builder 与本 pass 共用元胞折叠、逻辑转换及无 use 常量清理的实现。

### 后向全路径覆盖分析

旧 store 只有在所有后继路径都保证于读取、可能抛错或工作区观察前覆盖时才可删除。只跨越常量、PHI、goto 及已证明为具体 logical 1x1 的 branch。返回位置保留最终写入。分析从空的必然覆盖集合出发，纯循环不能用回边自证最终会发生覆盖。

变换重复至稳定后压缩值编号并发布版本。数据流求解期间不修改指令。

## 运行时边界

Non-SSA 读写优化仍保守处理动态指令；mem2reg 对普通运算及调用采用不修改当前工作区的 SSA 假设，显式工作区变化由屏障建模。二者不能混用同一套失效规则。

任意调试暂停点修改工作区需要执行保留实际读写的版本，或在修改后回退到该版本；已优化的 Non-SSA 不能直接承担任意修改后的恢复语义。运行时调试与回退协议仍待接入。
