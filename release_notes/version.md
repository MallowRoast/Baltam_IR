# Version 0.2.0

更新日期：2026-11-09。

## SSA 构建与回退信息

- 重写 mem2reg，采用基于 CFG 的按需定义查询及占位 PHI 处理分支和循环，不再依赖支配边界插入 PHI 或沿支配树重命名。
- 新增 `record slot_x, %N`，在原赋值位置独立记录已提升局部变量的运行时绑定。移除 Value 的 assigned_slot 字段及 CopyInst，多个变量可直接引用同一个 SSA 值。
- SSA 参数直接由函数签名定义为 Value，移除 ParameterInst；SSA 返回指令直接引用寄存器。克隆、Use 链和编号压缩支持签名参数，编号按参数、返回结果、函数体结果排列。
- 建立 Non-SSA 基线及跨阶段寄存器映射，值替换和编号压缩同步维护恢复来源；SSA 保存基线的非拥有指针。设计约定在实际回退时再按需分析需要恢复的寄存器。
- 支持 workspace_barrier 前后的定义查询、工作区状态读取及 Undefined 传播。移除来源必须“必然已定义”才能消除 load 的规则，约定由普通指令在实际取值时承担 Undefined 检查。
- SlotInfo 保存全局、持久声明和嵌套共享关系；相关变量保留真实 load/store。内部槽位通过 is_internal 标记，可跨工作区屏障提升，不生成 record。

## 循环与短路表达式

- ForeachInit 简化为单结果，返回 double 标量上限；语义包含双输出 size、第二输出的 double 转换和首元素提取，空结果按零次循环处理。
- 移除 ForeachIterate，逐轮取值改为原迭代源的 ParenReferenceInst，配合特殊冒号 ConstInst 和内部下标；单独冒号不再使用专用节点。
- 循环计数槽位固定为 double 1x1，load 和提升后的 PHI 继承类型与形状；比较及递增统一使用 gt_double、add_double。特殊冒号常量在循环体中创建。
- 按 SSA 中常规调用不修改当前工作区的假设处理 size/double/subsref 重载，不自动插入工作区屏障；明确的工作区操作仍通过屏障保护，实际跨帧修改按回退协议处理。
- Non-SSA 允许 PHI，无具名短路表达式直接在汇合块生成 PHI，不再引入临时 slot；直接变量赋值复用目标 slot，完整短路条件直接连接控制流。

## IR 格式与接口清理

- 寄存器定义统一为 `%N: type shape`，类型和 shape 可分别省略，未知维度使用 `?`；多结果调用使用 `[%N, %M: type shape]`。内部槽位类型从 load 标注恢复。
- 常量类型与 shape 移至结果编号之后，逻辑标量展示 `(true)`／`(false)`，字符向量和字符串标量保留可读展示值；constants 元数据及 MAT 存储继续用于精确恢复。
- SSA 参数使用 `%N [name=x]`，已知类型和 shape 按统一规则标注；调用节点仅保留同模块静态目标属性，移除冗余动态及分派标记、未使用的 DispatchType 和 intrinsic 多结果存储。
- 更新 IR 持久化、mem2reg、SSA 回退及语法设计文档，补充循环、工作区操作、内部槽位和条件绑定的 M 文件用例。
- opt 的版本输出改为从 CMake 项目版本生成，修正与项目版本不一致的问题。

本版本包含不兼容的 IR 文本和 C++ 接口变更，旧 IR 文件需要重新生成。当前完成的是 IR 构建、变换、持久化及静态回退信息；工作区绑定、Undefined 检查、size/double/subsref 执行和实际回退仍待运行时接入。

# Version 0.1.3

## SSA 分析与优化

- 新增 PHI 指令，以可选值表示 Undefined，接入 IR 持久化。
- 新增 `CFGAnalysis` 和 `DominatorAnalysis`，统一提供块索引、去重前驱与后继、直接支配、支配树、支配查询和支配边界。
- 新增函数 pass 管理器及 mem2reg，支持 `-passes=mem2reg` 和 `function(mem2reg)`；通过迭代支配边界插入 PHI，沿支配树重命名并移除可安全提升的局部槽位读写。
- 转换在独立阶段副本上完成，成功后发布基础 SSA，保留原 Non-SSA。对捕获、值包、定义前读取和可能改写工作区的操作采取保守策略。

## IR 数据结构与读写

- 用地址稳定的 Value 替换 ValueInfo，引入 Use/User 统一维护输入及双向使用链；替换、删除、克隆和编号压缩同步维护引用。
- 移除所有 IR 类的 `to_string()` 成员接口，统一由 ir_io 的非成员 `write_ir` 和文件读写接口处理格式，删除重复调试输出路径。
- 移除三个阶段的专用块访问器及未使用的节点级替换接口。ReturnInst 统一为无操作数的 `ret`，函数输出通过返回槽位传递；读取带操作数的 ret 时明确报错。

## 工程与文档

- 新增根目录格式化脚本、带中文尾后注释的 `.clang-format`、格式检查目标及可选构建前格式化。
- lambda 使用显式捕获；Analysis 和 Transform 的完整结构验证职责留给后续独立 Verifier Pass。
- 新增 mem2reg 设计、支配分析设计及 IR 生成正确性测试方案，更新 IR 组织、持久化与语法设计文档。
- 移除独立 C++ 测试程序、CTest 配置和辅助检查脚本，保留 M 文件样例。

# Version 0.1.2

## IR 持久化

- 新增 `ir_io.h/.cpp`，统一提供 `IRPrinter`、`read_ir`、`read_ir_file` 和 `write_ir_file`。打印器持有单次输出的常量编码状态，重复打印时重置标签，不将导出状态保存在 `IRModule` 中。
- 支持恢复模块、脚本、函数、嵌套函数、槽位、当前阶段的基本块及已支持文本表示的指令；恢复多结果调用的值表位置、调用分派属性和同模块静态目标。
- 移除 `module_info`，根据 `ModulePath` 和代码单元结构推导模块属性；从 IR 文件读取的模块用于观察，不注册到 M 源文件缓存。
- 调整输出排版：注释和基本块标签顶格，块内指令缩进 4 个空格，代码与常量元数据块之间使用空行分隔；保留函数阶段信息。

## 常量与 MAT 文件

- 新增常量编解码，采用 `%x = const !cN (value): type shape` 格式；可选展示值仅用于阅读，恢复以文件末尾的 `constants` 表为准。
- 常量按类型、完整形状和内容去重。简单类型中少于 10 个元素的常量内联保存，浮点使用固定宽度、最高有效位在前的十六进制位模式，保留负零和 NaN payload。
- 接入 `deps/mat_tool`：较大数组及支持的元胞、结构体使用配套 MAT 文件。每个文件保存一个 `value` 变量，使用相对路径，并在写出后读取校验，拒绝后端无法无损保存的数据。
- 精简编解码及读写辅助逻辑，统一新增代码注释和相关报错的中文表述。

## 命令行与文档

- 明确工具职责：`baltam_ir` 负责 M 文件转 IR；新增 CMake 目标 `baltam_opt`，生成 `opt`，负责 IR 转 IR。
- `opt` 支持 `-S`、`-o`、`-passes=`、标准输入输出、`-disable-output` 及 MAT 资源目录。当前仅支持空 pass 管线，尚未实现优化 pass，非空管线明确报错。
- 工具说明统一放在项目根目录 `README.md`，构建目录统一为 `build`。
- 新增 IR 持久化和函数调用点缓存设计文档。调用元数据与调用点缓存仍为设计，尚未接入运行时代码。
- 移除本轮新增的独立 C++ 测试文件及命令行 CMake 辅助脚本，保留原有 lowering 和缓存集成测试。

# Version 0.1.1

## 构建与文件加载

- 新增 `IRBuilder::build_file(path)`：解析脚本或函数型 `.m` 文件，构建包含脚本主体、文件级函数和多层嵌套函数的 Non-SSA `IRModule`；嵌套函数由词法父函数拥有。
- 文件模块接入 `IRCache`：按规范化的绝对路径复用有效模块；缓存失效时重建并替换条目，旧模块可由外部 `shared_ptr` 继续持有。文件修改时间按现有世界计数规则检查。
- 简化构建接口：移除 `AstReader`、`AstNodeView` 和 `InstructionBuilder`；`IRBuilder` 持有当前指令插入块，脚本与函数共用构建流程，基本块统一编号为 `bb0`、`bb1` 等。

## IR 输出与命令行工具

- 为基本块、脚本单元、函数单元和模块提供 `to_string()`；函数注释显示 `Non-SSA`、`Based-SSA` 或 `Optimized-SSA` 阶段，嵌套函数输出标注词法父函数。
- 新增 `baltam_ir` 命令行工具：接受相对或绝对 `.m` 路径，输出以绝对路径形式的 `ModulePath` 开头；支持 `-o <输出文件>`，默认写入标准输出。
- `utils/README.md` 补充构建、使用以及将 `build` 目录临时加入 Bash `PATH` 的步骤。

## 测试

- 增加常量、表达式、索引、成员访问、变量声明、分支、循环、短路逻辑、脚本、嵌套函数、多文件缓存和 CLI 输出文件等用例。
- 测试目标移入 `test/CMakeLists.txt`；合并重复的 C++ 测试文件，保留 IR lowering 与缓存集成测试两个测试程序。

# Version 0.0.1

首个 Baltam IR 版本，提供 C++17 静态库和 IR 设计文档。

## 代码结构

- `IRModule`、`IRUnit`、`FunctionUnit`、`CommandUnit`、基本块和阶段版本统一定义在 `ir_unit.h/.cpp`；模块管理源码信息、命令单元和函数索引。
- `FunctionUnit` 保存 Non-SSA、SSA、Optimized SSA 的 IR 版本和当前处理阶段；阶段版本拥有基本块、入口块与值表。
- 代码单元指向所属模块，基本块指向所属代码单元，指令指向所属基本块；嵌套函数通过专用接口加入并继承父模块。
- 槽位表只保存名称；值表保存定义指令、结果位置、值形态和常量标记。阶段版本检查值定义指令的归属。

## IR 指令与缓存

- 定义常量、槽位访问、数组和元胞构造、索引、成员访问、调用、运算、变量声明及控制流指令。
- 文件 IR 缓存按规范化的绝对 `.m` 路径索引模块，使用文件修改时间和世界计数检查有效性；世界计数实现位于独立的 `world_counter.cpp`。
- 移除了函数句柄构造指令；后续构建和执行语义仍需设计。

## 构建与样例

- CMake 项目版本为 `0.0.1`，构建目标为 `baltam_ir` 静态库。
- 移除了旧的 C++ smoke 测试，保留从 `dev_zj` 搬运的脚本样例 `test/m/test1/test1.m`，用于展示脚本中的 local 函数场景。
